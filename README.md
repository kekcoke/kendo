# Kendo Orchestration Loop & Target Platform

This repository contains both the **Agentic Orchestration Loop** (the virtual software factory) and the **Target Platform** (the highly resilient, multi-instance microservice ecosystem being built).

## 🏭 The Orchestration Loop

The orchestration pipeline processes daily curriculum tasks into production-ready code through a strict, 5-phase gated loop. 

1. **Phase 0:** State Initialization (`.ai/current_state.md`)
2. **Phase 1:** Architecture & Contract Design (Platform Architect)
3. **Phase 2:** Implementation & Validation (Developer + QA)
4. **Phase 4:** Delivery & CI/CD (DevOps / SRE)
5. **Phase 5:** Review, Merge & State Update (Reviewer)

## 🌐 Target Platform Architecture (Resilience & Scale)

The output of this factory is a distributed, multi-instance cloud platform designed for high availability. 

* **Multi-Instance Load Balancing:** All web APIs and background workers are containerized and deployed behind a reverse proxy/load balancer.
* **Circuit Breakers & Retries:** External API calls and database queries are wrapped in circuit breaker policies (e.g., Polly for .NET) to prevent cascading failures.
* **Async Workflows:** Heavy processing and state mutations are offloaded to an Event Bus (e.g., RabbitMQ/Azure Service Bus), allowing the API to return HTTP 202 (Accepted) immediately.
* **Graceful Degradation:** Services return standardized RFC 7807 Problem Details on failure, ensuring upstream services can parse and react to errors predictably.
