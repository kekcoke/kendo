## Day 20 — M0.6: UserService Event Domain + Embeddings Foundation
**MR:** [feat(day-20): UserService Event Domain + Embeddings Foundation (M0.6)](https://github.com/kekcoke/kendo/pull/26) · merged `6e133a9`

### Changed
- **4 new domain entities** — Event (domain root, 13 fields), EventValidation (1:1 with Event, W2 results), EventEmbedding (sidecar, pgvector vector column), UserEmbedding (sidecar, pgvector vector column)
- **3 new EF Core migrations** — AddEventDomain (4 tables with vector columns via raw SQL ALTER), AddFastAPIReadOnlyRole (SELECT-only grants for FastAPI Phase 05), AddEmbeddingAdminWriterRole (INSERT/UPDATE grants for scoped admin connection)
- **EventsController** — 5 JWT-authenticated routes: GET list (paginated, owner-scoped), GET by id (owner only), POST create, PATCH update (owner only), DELETE hard delete
- **EmbeddingAdminController** — POST /internal/embeddings (upsert, admin:writes scope + token_use=service), POST /internal/events/{id}/reindex (W5 backfill trigger)
- **AdminWriterConnectionFactory** — scoped Npgsql connection as userservice_writer role for defense-in-depth
- **JWT auth wiring** — AddKendoJwt(), AddKendoAdminScopePolicies(), UseAuthentication()/UseAuthorization() in UserService Program.cs
- **Dimension enforcement** — kendo.embedding_dim GUC set via startup hook from KENDO__EVENT_EMBEDDING__DIM env var (default 1024)
- **Docker compose + .env.example** — KENDO__EVENT_EMBEDDING__DIM=1024, KENDO__EVENT_EMBEDDING__MODEL=BGE-large-en-v1.5
- **Day 20 runbook** — deployment steps, rollback procedures, known issues for Event Domain operations
