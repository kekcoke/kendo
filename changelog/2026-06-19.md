## Day 24 — M5.5: FastAPI Resilience Parity (pybreaker + tenacity)
**MR:** [feat(day-24): FastAPI Resilience parity — pybreaker + tenacity + OpenTelemetry (M5.5)](https://github.com/kekcoke/kendo/pull/30) · merged `57bcb62`

### Changed
- **pybreaker circuit breakers** — Independent breakers for pgvector and Azure OpenAI (fail_max=3, reset_timeout=30s). State transitions logged via `CircuitBreakerListener`. Breakers wired in lifespan startup and stored in `app.state.resilience`.
- **tenacity retry** — `retry_db()` decorator wraps asyncpg pool/query calls with exponential backoff + jitter. `retry_llm()` retries on httpx transient errors (timeout, connection, 5xx) but excludes 4xx via custom `_retry_if_llm_transient` predicate.
- **OpenTelemetry tracing** — `init_tracing()` with OTLP or console exporter. `get_current_trace_id()` populates `trace_id` field in all RFC 7807 error responses. `TracePropagationMiddleware` extracts W3C `traceparent` from Gateway requests and creates child spans.
- **Wire resilience** — `db.py`: retry on `create_pool/check_connection`, CB gate on `get_pool()`. `main.py`: tracing init + breaker creation in lifespan. `problem_details.py`: `trace_id` now populated from active OTel span (was empty string).
- **18 new Python unit tests** — 9 circuit breaker (state transitions, independence, edge cases) + 9 retry (transient errors, 4xx exclusion, exhaustion, non-target exceptions).
- **New deps** — `pybreaker>=1.0.0`, `tenacity>=9.0.0`, `opentelemetry-*` packages added to `pyproject.toml`.
- **Roadmap updated** — `pybreaker`, `tenacity Retry`, `OpenTelemetry (FastAPI)`, `Trace Correlation (FastAPI)` all marked ✅ (Day 24).

### Deferred
- Chaos-test CI flakiness (`test_db_downtime`) — still unresolved, documented in M3.6 runbooks
- Day 17 closure items: IssuerSigningKeyResolver refactor; user JWT issuance; key rotation BackgroundService — carried forward
- M5.6 (observability: OpenTelemetry + chaos tests) — next milestone

### Fixed
- `_map_state` in circuit_breaker.py: pybreaker.state is a state object (not string constant) — fixed with type-name check
- `retry_llm`: 4xx HTTP errors wrapped in `httpx.HTTPStatusError` were being retried — fixed with custom `_retry_if_llm_transient` predicate
